# ─── AudiobookMaker — Fish Audio S2 Pro provider (tts_provider_name = "fish") ──
#
# TWO steps. Step 2 must use --no-deps:
#
#   pip install -r requirements/tts-fish.txt
#   pip install --no-deps descript-audiotools descript-audio-codec "fish-speech @ git+https://github.com/fishaudio/fish-speech.git@214da3cd841bda85da2496b96cd3c4d7edb1337e"
#
# Why --no-deps (and why those three packages are not listed below):
#   * fish-speech pins torch==2.8.0 / torchaudio==2.8.0, pydantic==2.9.2,
#     datasets==2.18.0 and modelscope==1.17.1, and pulls pyaudio (needs
#     portaudio headers), gradio, wandb, lightning and more. None of that is
#     used by in-process inference; installed normally it replaces the
#     notebook's torch and breaks this app's gradio / pydantic.
#   * descript-audiotools pins protobuf<3.20, which downgrades protobuf and
#     breaks tensorboard / transformers on current images.
#   * descript-audio-codec depends on descript-audiotools.
#   A requirements file cannot mark single lines as --no-deps, hence step 2.
#
# Already expected in the environment (do NOT let pip reinstall them):
#   torch, torchaudio built for that torch, transformers (upstream supports
#   <=4.57.3; 4.57.x is also what qwen-tts wants), tokenizers, safetensors,
#   huggingface-hub, numpy, scipy, rich, tqdm, click.
#
# The lines below are the modules fish-speech's inference path and the DAC
# codec import at load time (verified by importing them at the pinned commit):
#   text2semantic/inference.py, llama.py, lora.py -> loguru, einops, loralib
#   load_codec_model()                            -> hydra-core, omegaconf
#   dac / audiotools (import time)                -> argbind, flatten-dict,
#       julius, ffmpy, importlib-resources, randomname, tensorboard
#   this provider (reference clip I/O, resample fallback) -> soundfile, librosa
#
# Alternative to the fish-speech wheel: git clone the repository and export
# ABM_FISH_REPO=/path/to/fish-speech (the two descript packages and the lines
# below are still required).
#
# Weights: fishaudio/s2-pro, 11 GB, downloaded on first use; or export
# ABM_FISH_CHECKPOINT_DIR=/path/to/s2-pro to use a local copy.
